# Community Code of Conduct

ISC Expo Workshops aims to provide a welcoming, respectful, and constructive learning environment for people with different backgrounds, identities, abilities, and levels of experience.

## Our expectations

Expected behavior includes respectful communication, good-faith questions, useful feedback, acknowledging others' work, and accepting constructive corrections. Make room for beginners and explain jargon where possible.

Unacceptable behavior includes harassment, discrimination, threats, personal attacks, doxxing, unwanted contact, sharing private information, plagiarism, and intentionally disrupting learning spaces.

## Scope

This code applies to repository issues, pull requests, discussions, events or activities directly connected to these learning resources, and project spaces where contributors represent ISC Expo Workshops.

## Reporting

Report concerns privately to [info@iscexpo.edu.bd](mailto:info@iscexpo.edu.bd) with a link and a brief description. Do not post sensitive evidence publicly. Maintainers should review reports fairly, keep information confidential as far as practical, and take proportionate action, including a warning or removal from project spaces.

## Maintainer responsibility

Maintainers are responsible for clarifying expectations and applying this code consistently. A report should be handled without retaliation against the person who raised it in good faith.
