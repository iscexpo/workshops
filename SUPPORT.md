# Support

- **Content question or correction:** open an issue in this repository, without private information.
- **Workshop proposal:** use the workshop proposal issue form.
- **Contribution question:** read [CONTRIBUTING.md](CONTRIBUTING.md) or open a non-sensitive issue.
- **Security, conduct, or personal matter:** contact [info@iscexpo.edu.bd](mailto:info@iscexpo.edu.bd) privately.

When asking for help, include the workshop or file path, the step you are working on, what you expected, and the non-sensitive error message. Never share passwords, tokens, student records, or personal details in a public report.
