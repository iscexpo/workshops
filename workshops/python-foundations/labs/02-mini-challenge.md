# Mini Challenge: Workshop Summary

**Goal:** combine strings, numbers, variables, and a condition.  
**Suggested time:** 10–15 minutes.

## Task

1. Store a workshop topic in a string variable.
2. Store the number of activities in an integer variable.
3. Print a sentence describing the workshop.
4. If the activity count is greater than zero, print a message encouraging the learner to begin. Otherwise, print a message that the activities still need to be prepared.

## Example output

```text
Workshop: Web basics
Activities planned: 3
Let's begin with the first activity!
```

Your output can use a different topic and count. Do not add personal information.

## Stretch

Move the summary into a function that accepts the topic and activity count. Test it with both zero and a positive number.

## Reflection

What happened when you changed the activity count? Which line controls the decision?
