# Lab 3: Variables and Decisions

**Goal:** store a workshop topic and an activity count, then use a condition to choose a message.

## 1. Open the example

Open `examples/python_foundations/workshop_summary.py` and find the topic and activity count values used for the sample run.

## 2. Run the program

From the repository root:

```bash
python examples/python_foundations/workshop_summary.py
```

## Expected output

```
Workshop: Python Foundations
Activities planned: 3
Let's begin with the first activity!
```

## Experiments

1. Change the topic to another workshop name.
2. Change the activity count to `0`. Which message changes?
3. Change the condition to `activity_count >= 3`. Test with counts of `2` and `3`.
4. Explain what would happen if the `else` block were removed.

- What does the `f` before a string allow you to do?
