# Web Development Basics: HTML and CSS

**Level:** Beginner · **Duration:** 90 minutes · **Status:** Draft  
**Audience:** Learners who want to make a simple web page  
**Last reviewed:** Not yet reviewed

## Learning outcomes

- Explain the purpose of HTML and CSS.
- Add headings, paragraphs, and a link to a page.
- Use CSS to improve spacing and readability.
- Check that links are descriptive and the page remains readable on a narrow screen.

## Prerequisites and tools

A modern web browser and a plain-text code editor. No framework or account is required. Open `starter/index.html` directly in the browser and edit the file in the editor.

## Session plan

| Time | Activity |
|---:|---|
| 0–10 min | Identify the parts of a web page |
| 10–30 min | Read and edit the HTML structure |
| 30–50 min | Change colors, spacing, and font sizes in CSS |
| 50–70 min | Add a section and a useful link |
| 70–85 min | Peer review for usability and accessibility |
| 85–90 min | Reflection and next steps |

## Hands-on activity

Open [`starter/index.html`](starter/index.html). Change the page title, add a new heading and paragraph, and update `starter/styles.css` to change spacing. Reload the browser page after saving your changes.

## Quality checklist

- The page has one clear main heading and a logical heading hierarchy.
- Links describe their destination rather than saying only “click here”.
- Text has sufficient contrast and meaning is not conveyed by color alone.
- The page can be zoomed and remains readable on a narrow window.
- Important images (if added) have useful alternative text.

## Stretch activity

Add a list of three learning resources and a short section describing what you learned. Use only resources you have permission to link or reuse.

## Troubleshooting

- If changes do not appear, save and reload the page.
- Check that the CSS file path matches the `href` in the HTML.
- Use browser developer tools to inspect missing styles, but do not share private or identifying information in screenshots.
