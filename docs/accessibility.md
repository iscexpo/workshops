# Accessibility and Inclusive Learning

Use these checks when writing or reviewing workshop content.

- Use a clear heading hierarchy and descriptive link text.
- Provide alt text for meaningful images; mark purely decorative imagery as decorative in the source format where supported.
- Do not communicate meaning through color alone.
- Include text descriptions for screenshots, diagrams, and important visual outcomes.
- Keep examples readable, with consistent formatting and short steps.
- Explain acronyms and technical terms when first used.
- Provide keyboard-accessible alternatives to mouse-only steps where possible.
- Consider screen size, low bandwidth, offline access, assistive technology, and learners using shared devices.
- Offer more than one way to demonstrate learning when it fits the activity.
- Avoid collecting personal data unless it is necessary and has an appropriate lawful and organizational basis.

Accessibility needs vary. Ask learners what format or support helps them participate rather than making assumptions.
