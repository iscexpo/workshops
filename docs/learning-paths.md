# Suggested Learning Paths

These are suggested routes, not prerequisites or certifications. Adapt the order to your goals and available devices.

## Digital foundations

1. Identify files, folders, browser tabs, downloads, and safe file sharing.
2. Practice strong account security and learn to recognize suspicious links.
3. Learn to search for information, compare sources, and cite material responsibly.

## Python foundations

1. [Python foundations workshop](../workshops/python-foundations/README.md)
2. Run and modify the [hello Python example](../examples/python-hello/README.md)
3. Add a small feature, write a test, and explain your solution to a partner.

## Collaboration with Git and GitHub

1. [Git & GitHub collaboration workshop](../workshops/git-github-collaboration/README.md)
2. Practice a branch, a small change, and a pull request in a test repository.
3. Review another change kindly and use feedback to improve it.

## Web development

1. [Web development basics workshop](../workshops/web-development-basics/README.md)
2. Modify the supplied HTML and CSS starter files.
3. Check links, keyboard use, readable contrast, and layout on a narrow screen.

## For workshop facilitators

Use [the workshop template](../templates/workshop/README.md). Choose activities that work with the learners' devices, connection quality, language, and accessibility needs. Prefer no-cost, locally runnable tools where practical; document any account or service requirement before the session.
